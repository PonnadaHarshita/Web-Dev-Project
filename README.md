# Web-Dev-Project

A modern web development project showcasing an Amazon-like e-commerce platform with responsive design and product categories.

## 📋 Features

- **Responsive Design**: Mobile-friendly and works across all devices
- **Product Categories**: Browse products by category (Electronics, Fashion, Home, Beauty, Toys, etc.)
- **Modern UI**: Clean and intuitive user interface
- **Search Functionality**: Find products easily
- **Product Display**: High-quality product images and details

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Responsive styling and modern design
- **JavaScript**: Interactive features and functionality

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── index.css           # Stylesheet
├── README.md           # Project documentation
└── [Images]            # Product and brand images
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/PonnadaHarshita/Web-Dev-Project.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Web-Dev-Project
   ```

3. Open `index.html` in your web browser
